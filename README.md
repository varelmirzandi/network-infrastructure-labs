# Network Infrastructure & Routing Labs

Dokumentasi topologi jaringan, konfigurasi *routing & switching*, VPN *tunneling*, serta studi kasus *troubleshooting* menggunakan **MikroTik RouterOS** dan **Cisco Packet Tracer**.

## Cakupan Topik
- **Routing & Switching:** Static Routing, OSPF, VLAN, Inter-VLAN Routing, DHCP & NAT.
- **Security & Tunneling:** Firewall Filter Rules, WireGuard/GRE/EoIP VPN Tunneling, Manajemen Akses Remote.
- **Praktikum & Simulasi:** Konfigurasi layanan server (Web/HTTP, FTP, DNS) pada topologi jaringan kampus.
