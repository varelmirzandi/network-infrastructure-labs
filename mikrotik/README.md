# MikroTik RouterOS Lab Notes

Catatan konfigurasi dan alur *troubleshooting* jaringan berbasis RouterOS:
- **Routing & Switching:** Pengaturan IP *addressing*, *static route*, VLAN, dan *firewall* dasar.
- **VPN & Remote Access:** Penerapan *tunneling* antar-perangkat untuk akses manajemen yang lebih terkontrol.
- **Checklist Verifikasi:** Cek tabel *routing* (`/ip route print`), status *interface/bridge*, serta uji latensi dan *packet loss*.
